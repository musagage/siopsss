Tools

Paranet Lite

Paranet Lite is a lighter version of Paranet (a proprietary software application) that allows users to upload and share their video or image files over LAN with others via IP sharing or Ethernet. It's a locally hosted mini-social application.

Boulder

Boulder is a desktop application designed to explain coding snippets or program files through auto-enabled commenting system. Essentially, it provides with a generic code summary by commenting which section of code explains what, without an attempt to alter or modify program details. It's good if you're starting out with programming, it allows you to "learn and code" instead of running "vibe coding sessions 101".

Text-to-Speech/Speech-to-Text Converter

TTS/STT converter is a basic interactive desktop application that allows users to convert text to simple speech or convert speech to text. It's for moderate use cases, but savvy users can always enable extra features, including ML/DL to make speech more responsive and conversational.

Software Dispatch Network

Software Dispatch Network is a web based application that allows users to share any software with other users. It can be accessed locally or deployed globally via cloud. In essence, SDN is much of a "hub" for any software that users can upload and download.

Redtooth DEMO

Redtooth DEMO is an open-beta software under Project Equilibrium designed to challenge traditional data transfer protocols. It enables completely offline, wireless data transmission over distances exceeding 1,000 km without relying on the internet, cables, or fiber optics.
